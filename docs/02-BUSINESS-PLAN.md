# 02 — Business Plan

## Business model
SaaS B2C/B2B con Free, Pro, Analyst, Business/API ed Enterprise.

## Pricing hypotheses
- Free: €0
- Pro: €19–29/mese
- Analyst: €49–79/mese
- Business: €149–299/mese
- Enterprise: custom

Sono ipotesi iniziali da validare.

## Revenue
Subscription, API usage, enterprise integration, custom analytics, white-label e research reports.

## Costi
Il costo dei dati/licensing può essere il principale. Seguono infrastruttura, monitoring, support, payment e marketing.

## Go-to-market
MVP → beta 20–50 utenti → misurazione activation/retention → willingness-to-pay → ottimizzazione costi → estensione coverage.

## Positioning
Non un semplice clone di un comparatore: storico strutturato + analytics + backtesting + API + AI.

## KPIs
Signups, activation, DAU/WAU, conversion, churn, API usage, freshness, coverage, gross margin e cost per active user.
