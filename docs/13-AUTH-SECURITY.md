# 13 — Authentication & Security

## Authentication
OIDC/OAuth2 preferito. Access token brevi e refresh sicuro.

## Authorization
RBAC: Admin, Analyst, Premium, API Customer, Viewer.

## API security
Rate limits, quotas, API key rotation, scopes e audit.

## Application security
TLS, secure headers, validation, parameterized queries, secret manager, dependency scanning e least privilege.

## Tenant isolation
Record tenant-owned scoped by tenant_id e autorizzazione server-side.

## Audit
Log di modifiche amministrative, provider config, API key operations e accessi sensibili.
