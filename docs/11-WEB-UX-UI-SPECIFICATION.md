# 11 — Web UX/UI Specification

## Design direction
Premium data SaaS/admin, light/dark mode, tabelle dense ma leggibili, gerarchia forte e responsive.

## Layout
Sidebar + top bar + content area + optional detail drawer.

## Dashboard
KPI cards, charts, today's matches, major movements e data quality.

## Tables
Sticky header, sorting, filtering, pagination, column visibility e responsive fallback.

## Match detail
Market cards, bookmaker matrix, historical odds chart, team comparison e statistics.

## Team detail
Overview, standing, form chart, home/away split, historical matches e analytics.

## States
Loading skeleton, empty, partial data, provider stale, error e permission denied.

## Accessibility
Keyboard navigation, focus states, semantic tables, contrast e screen-reader labels.
